# Backlogger — next version

Planned features for the next version:

- **Sync with other devices**
  - Keep the desktop app usable offline.
  - Start with a user-managed folder or portable export/import flow before considering any hosted service.
  - Preserve local data and surface conflicts instead of silently overwriting edits.

- **Pin window in foreground**
  - Add an always-on-top toggle for the desktop window.
  - Persist the preference locally.

- **Mobile version**
  - Design a mobile client around the same task and category data model.
  - Define how local storage and device sync work before choosing the mobile implementation.
